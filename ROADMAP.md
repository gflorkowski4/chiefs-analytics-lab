# Chiefs Analytics Lab — Roadmap to 1.0

The Lab is a passion project: football analytics, taught in plain English through Chiefs plays. Every number traces back to a play. Every stat is taught one at a time.

**Hard launch: 1.0, post-Super Bowl, February 2027.** The launch is timed for the offseason dead zone, so bloggers and Chiefs outlets can use the Lab for offseason posts — and so we have the whole offseason to iterate before the 2027 season.

No rush. We have a lot of time to make this great. Features are added one at a time, in the design pattern we have (dark neumorphism, tokens in `style.css`, same nav / cards / stat system on every page). Once all the features are in, then we innovate the whole site more.
